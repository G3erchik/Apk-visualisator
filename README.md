# Визуализатор графа зависимостей для Alpine Linux (apk)

Инструмент командной строки на языке Python для анализа и визуализации 
графа зависимостей пакетов операционной системы Alpine Linux. 
Программа извлекает информацию о зависимостях напрямую из файлов пакетов 
(`.apk`), не используя сторонние менеджеры пакетов.

## 📌 Описание функций и настроек

Программа поддерживает следующие параметры командной строки:

* `-p`, `--package` — **(обязательно)** Имя анализируемого пакета.
* `-r`, `--repo` — **(обязательно)** URL-адрес репозитория с пакетами 
  (или путь к локальному файлу в тестовом режиме).
* `-t`, `--test-mode` — Включает режим тестирования. В этом режиме 
  программа не скачивает пакеты из интернета, а читает граф из локального 
  файла, где пакеты названы большими латинскими буквами (например, `A -> B`).
* `-o`, `--output` — Имя файла для сохранения изображения графа 
  (по умолчанию `graph.png`).
* `-a`, `--ascii` — Выводит зависимости в консоль в виде красивого 
  ASCII-дерева.

## 🚀 Команды для сборки и запуска

Для запуска программы требуется установленный Python 3.8+.
Сторонние библиотеки не используются (только стандартная библиотека Python).

**Для Windows (PowerShell или CMD):**
```bash
# Запуск в реальном режиме (скачивание пакета из интернета)
py src/main.py -p curl -r https://dl-cdn.alpinelinux.org/alpine/v3.19/main/x86_64/curl-8.5.0-r0.apk

# Запуск в тестовом режиме (из локального файла)
py src/main.py -p A -r test_graph.txt -t -a
